# Website CV - Gifari Candra Aji

Website CV Portfolio Gifari Candra Aji 

## Struktur File

```text
cv-Gifari-Website/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Cara Menjalankan

1. Ekstrak file ZIP.
2. Buka `index.html` di browser.
3. Edit data diri, skill, project, dan kontak sesuai kebutuhan.

## Cara Hosting di GitHub Pages

1. Buat repository baru di GitHub.
2. Upload semua file: `index.html`, `style.css`, `script.js`.
3. Masuk ke menu **Settings**.
4. Pilih **Pages**.
5. Pada bagian **Branch**, pilih `main`.
6. Klik **Save**.
7. Tunggu beberapa saat, website akan mendapatkan link GitHub Pages.
